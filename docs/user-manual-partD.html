PART D — How an admin sets cameras, analytics, reputation (Admin login only)

Screen: /admin → City operations (Camera registry, city analytics and reporter reputation… an admin never edits a verdict from here). Sign in with the one-tap Admin card (admin@pathlens.local / Admin@123). Reviewer/User sessions see the yellow box signed in as Reviewer/User… Admin-only — the API answers 403… Sign out and use the Admin demo account.

D1. Register a camera (all fields + what fails)

Panel Camera registry → form Register a new camera source. Fields in order: Provider (dropdown Datumfeed · FiveOneOneSfBay · SfMta · Caltrans · GenericPublicFeed · NycDot), External ID (required, e.g. SF_001), Label (required, e.g. Market St & 5th — SF Demo), City (any text, e.g. San Francisco), Latitude / Longitude (defaults 37.7749 / -122.4194), Feed image URL (absolute http(s), e.g. https://datumfeed.com/api/cameras/SF_001/image), Permission / terms note (e.g. Datumfeed Developer Agreement 2026-10-30, powered by Datumfeed, SF demo), Cadence (seconds) (min 60). Press Register camera. Failures print inline: Failed (400): …permission/terms note… (enable without note is refused by design), bad URL, bad coords, bad provider. Success: Camera registered successfully.

D2. Enable, poll, import, stale (the live loop)

Table columns Camera / Feed / Status / Actions. Row: label + provider · city, feed URL + last success, pill Active/Inactive + No permission note — cannot enable / lastError. Buttons: Edit (feed URL + permission note, Save/Cancel), Enable/Disable (Enabled/Disabled.), Poll now (Poll 200: Changed / Unchanged / CandidateCreated / Failed: reason). Header helpers: Enable all eligible, Poll all active, Import N active Datumfeed cameras (city + limit inputs; needs server key or Import failed (400): Datumfeed API key not configured). Footer truth: Enable a camera, then Poll now… square C marker — evidence, never a verdict. Mechanics to quote on camera: unchanged SHA-256 → nothing; changed → CameraFeed evidence on nearest report ≤100 m else auto CameraDetected candidate (Unknown/Unverified) into the Meta AI queue; dark/blurry/changed-view frames stored but flagged no AI analysis will run; daily budget + 60 s cadence enforced; live auto-polling is OFF on the demo so trigger manually. Stale = no success in 10 min — flagged, never trusted.

D3. City analytics + reputation (read-only)

City analytics — all cities (live GET /api/admin/stats): Total reports · Human-verified % · Stale >30d % · Unknown share (map) · Feedback wrong/stale of total · Reports per day last 7 chart (+ Run ./scripts/seed-sf.ps1 to populate when empty). Reputation: Bronze 1+ / Silver 3+ / Gold 5+ verified reports — empty on the demo (seeded reports have no author), shown as empty, never invented. Footer: Feedback is grouped weekly… a tap never changes verification.
