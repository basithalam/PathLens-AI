PART A — How to post a new report (public, no login)

Screen: /report/new (top-right + Report on every page). Works in any city. Nothing here needs an account.

A1. Open the form

Click + Report. You see Report an accessibility obstacle with the note: A new report starts as Unverified — a reviewer verifies it later.

A2. Fill the fields top to bottom

1. Title (required, max 200). Name the place so a stranger can find it. Good: Zindabazar crossing — rickshaw stand on the ramp. Bad: blocked. Under the box the error reads Title is required if you leave it empty.

2. Description (optional) (max 2000). What blocks it, how much width is left, when you saw it. Example: Two slabs lifted at the joint by the tree, front wheels catch. Seen 4 Nov 2pm. After photo shows repaved.

3. Obstacle type (dropdown, default Unknown): BlockedSidewalk · BrokenSurface · MissingOrBlockedRamp · StairsOrStep · ConstructionBarrier · Other · Unknown. Pick the closest visible thing. Broken slabs = BrokenSurface. Scooters across path = BlockedSidewalk. Unsure = leave Unknown.

4. Severity (default Unknown): Unknown · Low · Medium · High. Lip across walking line that can tip a chair = High. Cosmetic crack = Low.

A3. Location — three ways, pick one

Option 1 — Use my location (button). Browser GPS fills Latitude/Longitude and shows e.g. Location filled from your browser (accuracy about 12 m). Check it before submitting. Over 50 m it adds Accuracy is low (>50m) — drag the map pin to fine-tune; over 100 m Very low — please verify on map. If permission was denied: Location permission was denied. Enter coordinates manually.

Option 2 — Pick on map (button toggles to Hide map picker). An embedded map opens; click to drop the pin, drag to adjust. It writes 6-decimal coordinates and the note Picked on map — lat, lon. Drag the marker or click again to adjust.

Option 3 — type numbers directly into Latitude (-90..90) / Longitude (-180..180). Wrong range gives a field error on submit.

The page reminds you: Coordinates you enter are a claim about where the obstacle is, not a verified fact.

A4. What did you actually see? (the honesty block)

Fieldset What did you actually see? (optional — Unknown is honest): Stairs or a step here? Unknown/Yes/No · Ramp here? Unknown/Yes/No · Surface Unknown/Smooth/Uneven/Broken. Only set what you observed yourself. A wrong No is worse than an honest Unknown — the route card later reads Stairs/ramp/surface not measured here (unknown, not estimated).

A5. Consent + submit

Tick the consent box (required — my own photo, no faces/plates, storage per retention policy; removal via maintainer request, no delete button yet). Press Create report (shows Saving…). Offline? It says Saved locally — will send when online and queues it. Success takes you straight to the new report page, status Unverified.

A6. Add photo + run Meta AI (same report page, Photo evidence)

Under Photo evidence click the drop zone (Choose a photo or drop it here), optionally set When was this photo taken? (your claim; empty = upload time, and comparisons lose time-trust without it). Press Upload photo (progress bar shows percent). Each card then offers Run analysis (or Retry analysis after Analysis failed). Result card: Possible obstacle tag, AI confidence bar with percent + Low/Medium/High verdict, Obstruction share (sam-3.1, in-photo percent or not measured), Visible evidence bullets, Limitations, provider badge Live Meta AI — Meta · muse-spark-1.3 vs red Demo/mock — not real AI, and yellow Human review required. Photos paginate 5 per page.

A7. Compare + feedback + edit

Evidence explorer — compare over time: pick Earlier photo + Later photo, press Compare photos (needs Completed analysis on both). Outcome card: LikelyStillPresent · NotObservedInNewImage · ConflictingEvidence · Inconclusive with explanation + reviewer note box. Quick feedback: four buttons Still visible / Not in new photo / Information wrong or old / Not sure + optional note (max 2000) — Thanks — recorded. It does not auto-change verification. Edit: Edit report link opens Title/Description/Obstacle type/Severity + Save changes (location is intentionally not editable).
